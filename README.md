# 实验室报修跟踪

单实验室公共设备报修项目。成员提交报修，负责人接单、记录进度并提交验收，报修人试打后确认关闭或退回。

## 本地启动

准备 Python 3.12 和 `uv`，在包含 `manage.py` 的练习目录中运行：

```powershell
uv sync --locked --python 3.12
uv run --locked python manage.py migrate
uv run --locked python manage.py seed_demo_accounts
uv run --locked python manage.py runserver 127.0.0.1:8000
```

打开 [登录页](http://127.0.0.1:8000/login/)。项目依赖由 `uv.lock` 锁定为 Django 5.2.19 及其传递依赖，SQLite 由当前 Python 提供。可以用以下命令查看实际版本：

```powershell
uv run --locked python -c "import sys, sqlite3, django; print(sys.version.split()[0], django.get_version(), sqlite3.sqlite_version)"
```

## 演示账号

| 角色 | 用户名 | 本地演示密码 |
| --- | --- | --- |
| 普通成员 | `demo_member` | `LabDemo-Member-2026!` |
| 负责人 | `demo_handler` | `LabDemo-Handler-2026!` |

上述账号和开发服务器配置仅用于本机演示。账号存于根目录的 `db.sqlite3`。停止服务器后重新运行最后一条启动命令即可继续登录。重复执行初始化命令会保留现有账号和密码。遇到同名账号状态或角色冲突，或负责人组已有额外权限时，命令会报错。

## 验证

```powershell
uv run --locked python manage.py check
uv run --locked python manage.py test
```

1. 在未登录时直接打开 [应用首页](http://127.0.0.1:8000/)，应跳到登录页。
2. 用普通成员登录，首页显示「普通成员」。直接访问 [负责人入口](http://127.0.0.1:8000/handler/) 应收到 403。
3. 退出后用负责人登录，首页显示「负责人」，可以打开负责人入口。
4. 按 `Ctrl+C` 停止开发服务器并重新启动，两个账号应仍能登录。

## 提交报修

升级已有练习目录后，先按启动步骤执行 `migrate`。用普通成员登录，在首页打开「提交公共设备报修」。填写设备名称「公共打印机」、位置「实验室公共区」和故障描述「卡纸，无法打印」。提交后，首页会显示新工单编号和「待接单」。留空任一项会提示补填，已填写的内容会保留。

在首页打开「我提交的工单」，可以按最近更新时间查看自己提交的记录。待接单工单的跟进人显示「尚无跟进人」。点击工单编号可核对设备名称、位置、故障描述、状态和最近更新时间。自动化测试使用两个普通成员账号验证，直接访问别人的工单详情和访问不存在的工单都会收到同样的 404 页面。

工单列表每页 25 条。新报修的设备名称、位置和故障描述分别最多 160、240 和 4000 字符。较长的历史设备名称在列表显示摘要，详情保留全文。同一份报修表单重试会返回原工单，另报一张工单时请重新打开报修表单。

用负责人账号登录，从首页打开「负责人入口」，可切换「待接单工单」和「我接下的工单」，并点击编号查看详情。普通成员使用「我提交的工单」查看自己提交的记录。

负责人在待接单工单详情点击「接单」后，工单进入「处理中」并出现在「我接下的工单」。报修人刷新详情即可看到跟进人。若另一位负责人已接下同一张工单，旧页面提交时会提示刷新待接单列表。

## 用打印机卡纸验收

1. 用普通成员账号提交「公共打印机卡纸」。用负责人账号接单，在详情追加一条或多条处理进度。报修人在详情可看到跟进人、最新进度和记录时间。
2. 负责人填写处理结果并点击「提交验收」。报修人试打一页，成功时点「确认修好并关闭」。
3. 用另一张工单验证失败路径。报修人填写「试打仍卡纸」并点击「退回继续处理」。原负责人在原工单上继续处理并再次提交验收。复测通过后由报修人关闭，详情保留前后两轮处理结果及退回原因。

`uv run --locked python manage.py test` 会验证两条路径、角色权限和旧页面提交。独立的临时 SQLite 文件测试还会验证同轮关闭与退回竞争、事件写入失败回滚和真实写锁超时。

操作遇到版本冲突或数据库暂时不可用时，错误页提供详情入口。已经填好的有效进度、处理结果或退回原因可从页面复制，再按最新工单状态重新提交。单条进度、处理结果和退回原因最多 4000 字符。
