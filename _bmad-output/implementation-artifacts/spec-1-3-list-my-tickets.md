## Intent

**问题**　报修提交后，成员需要找回自己的工单并查看当前状态。

**方案**　从首页进入「我提交的工单」。服务端按当前会话成员过滤记录，展示编号、设备名称、状态、跟进人和工单最近更新时间。没有跟进人时显示「尚无跟进人」。用两个普通成员验证双向隔离。

</frozen-after-approval>

## Implementation Notes

- 首页提供「我提交的工单」入口。服务端以当前会话账号过滤报修人，忽略 URL 查询参数中的身份信息。列表响应带 `no-store`。
- 页面显示编号、设备名称、状态、跟进人和本地时区的最近更新时间。未分配跟进人显示「尚无跟进人」。先按更新时间倒序排列，时间相同时按工单编号倒序。无记录时显示空列表提示。
- Django 系统检查、迁移一致性检查和 21 项自动化测试通过。在临时 SQLite 文件上用两个实际普通成员账号登录、提交不同工单并查看列表，验证双方看不到对方的工单，即使请求中指定对方的报修人编号。
- 当前 Git 根在练习目录上级，无独立的项目提交基线。实现保存在练习目录。
